# Atas88 — Online Casino Malaysia

A starter repository for an informational website about Atas88 and online gaming in Malaysia.

## Project goals
- Present clear, mobile-friendly information.
- Use accessible HTML and responsive styling.
- Avoid misleading claims about bonuses, winnings, licensing, or safety.
- Encourage visitors to check local laws and the site's applicable terms before using any gaming service.

## Files
- `index.html` — single-page starter site
- `styles.css` — responsive styles
- `robots.txt` — basic crawler guidance
- `sitemap.xml` — starter sitemap (replace the example domain before publishing)

## Run locally
Open `index.html` in a browser. No build tools are required.

## Before publishing
1. Confirm that operating and promoting the service is lawful in each target location, including Malaysia.
2. Add only verified company, licensing, privacy, contact, and terms information.
3. Replace `https://example.com/` in `sitemap.xml` with your verified canonical domain.
4. Do not publish unsupported claims about guaranteed rewards, earnings, or winning chances.
5. Add a privacy notice and any age/eligibility notices required by applicable law.
